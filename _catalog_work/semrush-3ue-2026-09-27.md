1. **`db=global` is not a real Semrush database** — it resolves to `db=us`. Global demand is reported via the **Global Volume** metric and the country breakdown captured above.
2. Metrics are Semrush desktop, **date 2026-09-27**, currency **USD**; rankings snapshot dated **2026-09-25**.
3. `what is an industrial plug` and several low-tail question phrases return **no data** in Semrush.
4. The Organic Rankings report lists 255 US keywords; the seed terms do **not** appear among them, and the domain is absent from the top-10 SERP of every seed (verified against each keyword's SERP Analysis panel).
5. Explicit Semrush **“breakout/near-breakout” trend tags** were not separately captured in this run; the “Breakout / high-opportunity” table above is derived from volume × KD% × intent × CPC. A follow-up Keyword Magic Tool run with the trend/breakout filter would add rising-volume tags.
