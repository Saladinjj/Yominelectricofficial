Solar Combiner Box: What It Is, How It Works, and How to Choose

ET Engineering Team 9 min read · August 31, 2026

A solar combiner box is the enclosure where the DC output cables of multiple PV strings are brought together and combined into a single output that runs to the inverter. It houses string fuses (or circuit breakers), surge protection, and often an isolator and monitoring — protecting both the array and the maintenance technician.

If you are an installer, EPC contractor or distributor sourcing combiner boxes for commercial rooftop or ground-mount projects, this guide covers what goes inside the box, how string count and voltage drive the specification, and how to avoid the two most common field failures: under-fused strings and missing surge protection.

Why a PV System Needs a Combiner Box

Every solar array with more than one string needs a point where the strings converge. A combiner box does four jobs:

  • Combines strings — multiple positive and negative string cables connect to one main output feeder.
  • Protects each string — a fuse or breaker per string isolates a faulted string without taking the whole array offline.
  • Protects against surges — DC surge protection devices (SPDs) clamp lightning-induced transients before they reach the inverter.
  • Provides safe isolation and monitoring — a visible isolator for maintenance, plus optional current/voltage monitoring per string.

Without per-string fusing, a shorted or back-fed string can overheat the cabling and start a fire; without surge protection, nearby lightning strikes are a leading cause of inverter failure.

Key Specifications to Choose

1. Number of inputs (strings)

Combiner boxes are sold by input/output count — e.g. 2-in-1-out, 4-in-1-out, 3-in-3-out. Count your array's strings, then allow spare inputs for future expansion. A 4-input box is the most common choice for small commercial rooftop systems.

2. System voltage: 1000 V vs 1500 V

Rooftop systems typically run 1000 V DC; large ground-mount utility plants increasingly use 1500 V to reduce cable losses. The combiner box, fuses and SPD must all be rated for the system voltage — never mix a 1000 V box into a 1500 V array.

3. Fuse rating per string

Each string fuse must be rated above the string's maximum series fuse rating but below the cable's capacity — typically 10–20 A for residential modules and up to 32 A for high-current commercial modules. Confirm the exact value from the module datasheet.

4. Surge protection

Check that the box includes a DC SPD with the right voltage class (e.g. 1000 VDC, 40 kA max discharge) and that it is replaceable without rewiring the whole box.

5. Enclosure rating

Outdoor installations need at least IP65 with UV-stabilised housing; metal boxes add mechanical strength but need proper earthing. Indoor or string-level (micro) combiners can use lower ratings.

String Combiners vs Recombiner Boxes

In large plants you will meet both terms:

  • String combiner box — combines strings at the array edge; the box in this guide.
  • Recombiner box — combines the outputs of multiple string combiner boxes at a central point before the inverter or substation.

Buying Checklist

  1. Confirm string count and per-string fuse rating from your module datasheet.
  2. Confirm system voltage class (1000 V or 1500 V) — every internal component must match.
  3. Verify DC SPD inclusion and type (Type 2, voltage class, kA rating).
  4. Check enclosure IP rating and material for your installation environment.
  5. Confirm earthing points, cable gland sizes and whether MC4/connector type matches your string cables.
  6. Ask whether monitoring (string-level current sensing) is available for plant analytics.
  7. Verify certifications (IEC for fuses/SPDs, e.g. TUV-listed components) and the manufacturer's warranty.

FAQ

Do I need a fuse in every string?

Yes when three or more strings are combined in parallel. A fault in one string would otherwise be fed by the others; per-string fuses limit the fault current and prevent cable damage.

Can I use an AC combiner box for DC strings?

No. DC and AC protection have different breaking characteristics and voltage ratings. Use a box explicitly rated for DC PV use.

What is the difference between a combiner box and a junction box?

A junction box is a passive connection point. A combiner box adds protection (fuses, SPD, isolator) and is the correct choice for string combining.

Where should the combiner box be installed?

As close to the array as practical while staying accessible and shaded where possible — typically on a wall near the array edge or on the racking. Keep cable runs short to limit voltage drop.
